Statistical power

Statistical power

Important

Statistical power is defined as the probability, before a study is performed, that a particular comparison will achieve “statistical significance” at some predetermined level (e.g. \(P < 0.05\)) given an assumed true effect size.

WarningThe process
  1. Hypothesise an appropriate effect size (e.g. what effect will improve health?)
  2. Determine the \(p\)-value threshold you consider “statistically significant”
  3. Make reasoned assumptions about the variation in the data (e.g. what distribution? what variance?)
  4. Choose a sample size
  5. Use probability calculations to determine the chance that your observed \(p\)-value will be below the threshold (accept the null hypothesis) for the hypothesised effect size

  • The a priori statistical power of an experiment is the probability, before the study is performed, and assuming that there a minimum meaningful effect size, that the results will achieve “statistical significance” at some predetermined level (e.g. P<0.05).

  • The way you approach this should be as follows:

    • First, define what is a meaningful effect size (e.g. how much does cholesterol need to be lowered for this to be a meaningful change)
    • Then determine what level of statistical significance you can accept (e.g. P<0.05); this represents how willing you are to get an incorrect result, just by chance.
    • Make a reasonable guess about the level of variation you expect to see in the data
    • Choose a sample size for the experiment
    • Then use probability calculations to determine the probability that the resulting p-value will not be “significant,” even if the effect size you expect is true.

Effect sizes

WarningPower analysis depends on an assumed effect size
  • The true effect size is almost never known ahead of time
    • Determining the effect size is usually why we’re doing the study
TipHow to choose effect sizes
  • Try a range of values consistent with relevant literature
  • Determine what value would be of practical interest (e.g. improvement in outcomes of 10%)
ImportantHow not to choose effect size
  • DO NOT USE AN ESTIMATE FROM A SINGLE NOISY STUDY!
    • Noisy studies suffer from The Winner’s Curse

As you’ve seen, we need to specify some values before we start

  • Effect Size
  • Probability Threshold
  • Variation/Variance of the data

To some extent, we do not know these values - so we have to assert reasonable values before we start.

  • Effect size should be scientifically motivated: what is a reasonable and biologically-meaningful change in this context?
    • Are there useful examples from the literature?
  • We do not know variance in advance either, so we have to make a reasoned assumption - often “high/low/medium” variance, rather than a single value.
    • Again, are there useful examples from the literature?
  • For probability threshold we need to decide whether we can tolerate being incorrect.

It is tempting to run a small pilot study to estimate values; but this can be highly counterproductive because of something called the winner’s curse

The Winner’s Curse 1

CautionA low-powered pilot study
  • Suppose we ran a small pilot study with only a few individuals
  • The study, by design, has low statistical power
    • The variance of the data is relatively large, compared to the true effect size

To see what I mean, suppose that we ran a pilot study for a treatment where the true effect size was only a two percentage point increase in the outcome, but this effect is estimated with a standard error of about eight percentage points (because we only have a few individuals in the sample).

  • We test this against the null hypothesis that the effect size is zero

  • We set up the null hypothesis so that the result of the study is “positive”/“statistically significant” if the measured difference is more than two standard errors away from zero - i.e. outwith the orange shading of the curve

  • Even though the actual true mean effect is 2%, the larger standard error means that there is the possibility of the measured result falling outside that central shaded area

The Winner’s Curse 2

CautionYou get a statistically significant result!
  • You think you won, but you lost! (The Winner’s Curse)
    • The estimate is either eight times too large (at least 16% instead of 2%) or
    • The estimate has the wrong sign (a negative change instead of positive)

  • In this low-powered pilot experiment, any “statistically significant” result must fall into one of the dark purple sections of the curve at the extremes

  • The problem is this:

“Statistically significant” small pilot studies can be extremely misleading!

The Winner’s Curse 3

ImportantThe trap

Any apparent success of low-powered studies masks larger failure

When signal (effect size) is low and noise (standard error) is high, “statistically significant” results are likely to be wrong.

Low-power studies tend not to replicate well

Warning

Low-power studies have essentially no chance of providing useful information

We can say this even before data are collected

CautionPublished results tend to be overestimates

What this means is that “successful” pilot studies can mask larger failures.

  • If the effect size is smaller than the standard error/noise, pilot studies are likely to be quite wrong

You can quite frequently see the phenomenon, in the literature, of early positive (and small) studies being replicated with better datasets, and no meaningful effect being found. Even better-conducted studies with large effects tend to be revised by replication so that the observed effect size is not so large.

Low-power studies can be useless, and seen to be so before an experiment is performed

Statistical power and ethics

ImportantIt is unethical to under-power animal studies

Under-powered in vivo experiments waste time and resources, lead to unnecessary animal suffering and result in erroneous biological conclusions (NC3Rs Experimental Design Assistant guide)

CautionIt is unethical to over-power animal studies

Ethically, when working with animals we need to conduct a harm–benefit analysis to ensure the animal use is justified for the scientific gain. Experiments should be robust, not use more or fewer animals than necessary, and truly add to the knowledge base of science (@Karp2021-lc)

WarningSo how should we appropriately power animal studies?

What does this mean, ethically?

  • Underpowering studies means the results are not reliable. Detection of an effect is likely to be misleading, and result in more experiments - and animal suffering - before it is realised there is nothing useful to be found.

  • Overpowering studies (using too many subjects) means that we cause animal suffering for no purpose.

Both of these are unethical. So what should we do?

Statistical power and error 1

We often refer to two kinds of statistical error

TipType I Error (\(\alpha\))
  • Type I error is the probability of rejecting a null hypothesis, when the null hypothesis is true
    • Also known as a “false positive error”
  • Represented by the Greek letter \(\alpha\)
NoteType II Error (\(\beta\))
  • Type I error is the probability of accepting a null hypothesis, when the null hypothesis is false
    • Also known as a “false negative error”
  • Represented by the Greek letter \(\beta\)
ImportantStatistical power is \(1 - \beta\), for a given \(\alpha\) value and effect size

Whate we need to do is adequately power our experiments, but no more than this.

To do this, we need to decide how willing we are to be wrong in our conclusion, and what level of error we can tolerate. This means there are two different kinds of error we need to be concerned with.

  • Type I error is a “false positive error” - rejecting a null hypothesis when we should accept it.
    • In practical terms that means something like detecting a cancer when there’s none present. If the chemotherapy is severe, especially if it’s worse than the cancer itself, then this would be costly and painful and best avoided, and we’d want to minimise this error. If the treatment is a small, inconsequential surgery, then we might accept a higher error rate.
    • This is the meaning of the P-value in your null hypothesis test: P<0.05 means that there’s less than a 5% chance of a “positive” result being false.
  • Type II error is a “false negative error” - accepting the null hypothesis when we should reject it.
    • In practical terms, that means something like failing to detect a cancer when it is present. If the cancer is benign, then we can accept a fairly high error rate. But if it is fast-acting, painful, and deadly if not treated, we want to minimise the error rate.
    • At a specific level of type I error rate, this is the power of your experiment.

The choice of acceptable error rates - the desired power of the experiment - depends on the application.

Statistical power and error 2

Statistical power needs context: the expected error rates of the experiment at a given effect size, e.g.

The experiment has 80% power at \(\alpha = 0.05\) for an effect size of 2mM/L

TipHow to read this
  • “an effect size of 2mM/L”: we are aiming to detect an effect of at least 2mM/L (e.g. blood glucose concentration)
  • “\(\alpha = 0.05\)”: we are using a significance test threshold (\(\alpha\), type I error rate) of \(P < 0.05\)
  • “80% power”: we expect the study to report a significant effect, where one truly exists, 80% of the time

Statistical power also needs another value, for context: the size of the effect you’r trying to detect.

There are conventions for type I and type II errors \(\alpha\) and \(\beta\), but effect size is absolutely context-dependent. Typically:

  • \(\alpha = 0.05\)
  • \(\beta = 0.8\)

The statement here: “The experiment has 80% power at \(\alpha = 0.05\) for an effect size of 2mM/L” means:

Assuming there is an effect size of 2mM/L (e.g. a change in cholesterol concentration), and when a sufficient sample size that we would expect to detect this effect at P<0.05, the probability of still not seeing this effect (or a larger effect) is 0.2 (i.e. 20%).

Statistical power and error 3

ImportantIf the drug truly has no effect
  • The test has \(\alpha = 0.05\), so we would expect to reject the null hypothesis incorrectly 5% of the time
  • If we ran the experiment 100 times, we would expect to see a result implying that the drug was effective five times
TipIf the drug truly has an effect
  • The test has predicted power \(1 - \beta = 0.8\), so the type II error rate \(\beta = 0.2\) and we would expect to accept the null hypothesis incorrectly 20% of the time
  • If we ran the experiment 100 times, we would expect to see a result implying that the drug was effective eighty times
WarningWe should believe our results

\(0.8 / 0.05 = 16\) so a positive result is 16 times more likely to be real than mistaken

\(0.95 / 0.2 = 4.75\) so a negative result is ≈5 times more likely to be real than mistaken

So, with this level statistical power, if there was no effect of the drug:

  • If we ran 100 experiments we would expect to incorrectly say the drug has an effect 5 times

And if the drug truly had an effect:

  • If we ran 100 experiments we would expect to correctly say the drug has an effect 80 times.

So, if we get a positive result, it is 16 times more likely to be a true positive than a false positive.

And, if we get a negative results, it is five times more likely to be a true negative than a false negative.

Statistical power and sample size 1

TipWhat we need, to calculate appropriate sample size
  • An acceptable false positive rate (type I error, \(\alpha\))
  • An acceptable false negative rate (type II error, \(\beta\))
    • This is equivalent to knowing the target statistical power (\(1 - \beta\))
  • The expected effect size and an estimate of the variance of that effect size
  • The statistical test being performed
Important

We need this information to calculate an appropriate, ethically justifiable sample size

So, to calculate an appropriate, ethical sample size, we need to decide or provide:

  • acceptable false positive and false negative rates (i.e. statistical power)
  • an expected effect size and variance
  • and to know what statistical test is being performed, because this determines how we calculate an appropriate sample size to achieve the desired power

Statistical power and sample size 2

ImportantTypical funders’ requirements

  • False positive rate \(\alpha = 0.05\)

  • Power \(1 - \beta = 0.8\) (80% power)

  • These are only a starting point - other values may be more appropriate depending on circumstance

WarningUnder experimenter control
  • Effect size and variance
  • The appropriate statistical approach

The required level of statistical power is often decided by the funder or ethical committee.

The usual standard is to set a false positive rate of 0.05 (your P-value) and set the power at 0.8.

But determining effect size, variance, and an appropriate statistical approach is your responsibility as a scientist and you need to make your case to the funder and ethical panel for why your choices are acceptable.
